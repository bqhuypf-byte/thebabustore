# Mẫu file đầu ra — mô tả chi tiết sản phẩm chuẩn SEO

File này là khung cố định cho mọi sản phẩm. Copy cấu trúc, thay nội dung. Khớp với cấu trúc trang chi tiết đã duyệt (KZ Pisces) để Codex đưa thẳng vào template.

# <Tên sản phẩm đầy đủ — H1, chứa từ khóa chính>

- **Meta title (50-60 ký tự):** <tên sản phẩm> | <1 lợi ích chính> — The BABU Store
- **Meta description (140-160 ký tự):** <tên sản phẩm> <lợi ích chính>. <1 thông số nổi bật>. Giá <giá>. Bảo hành <thời gian>. Giao nhanh toàn quốc.
